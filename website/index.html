TRY ONE DEPENDENCY CHAIN

Start with your existing project.

  1. Download and extract the installation ZIP from the Release.
  2. In chrome://extensions, enable Developer mode and load the extracted folder containing manifest.json.
  3. Refresh ChatGPT, open GptWorkBot, connect a project and bind one supervisor and your Work roles.
  4. Connect collaboration, give the supervisor a goal, then review and confirm the plan in the sidebar.
