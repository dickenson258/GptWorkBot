## 简体中文

2026-10-12 · 1.1.0 → **1.2.0**，自动递增中间版本位。

- 插件生成的连接说明、角色初始化、任务结构、成果输入、回传及修订提示跟随中英文界面语言。用户任务、职责和成果保持原文。
- 修复原生最终回复缺少 Work 外层标记时，就绪确认一直等待的问题；升级后重新核对已有会话，无需重发初始化。
- 主管连接说明包含当前项目业务任务登记快照，区分已输出、已登记、已批准与已送达。英文 Analysis／Marketing 示例按角色名称匹配。
- 首次发送前保存完整消息和语言，重试复用原内容、输入快照及发送标识；仍检查暂停和前置依赖。

**安装**：下载并解压 `gptworkbot-1.2.0.zip`，在 Chrome 开发者模式加载含 `manifest.json` 的目录。当前未上架 Chrome 扩展商店。

**升级**：更新原扩展目录、重新加载扩展、保存草稿后刷新 ChatGPT、重开侧栏并重新核对会话。已有 v2 团队和任务保留，不需要重新绑定；从 v1 升级才需重新绑定并连接协作。

**验证**：18 个文件、334 项自动化测试、严格类型检查、构建及安装 ZIP 校验通过。真实页面只读检查和 DOM 回归分别记录；完整已安装协作流程仍保留人工验收项，见[验证记录](../verification.md)。

附件：安装 ZIP；离线中英文首页 ZIP。既有版本包和归档保持不变。

## English

October 12, 2026 · **1.2.0** automatically increments the minor version from 1.1.0.

- Generated connection guidance, role initialization, task structure, result inputs, reports and revision prompts follow the Chinese or English interface language. User instructions, responsibilities and results retain their original text.
- Fix connections waiting indefinitely when a native final reply lacks the Work wrapper. Recheck existing conversations after upgrading; no initialization resend is required.
- Supervisor connection guidance includes the current project's business-task registry snapshot, distinguishing output, registration, approval and delivery. Analysis/Marketing examples match English role names.
- Persist the complete message and language before the first send. Retries reuse the same content, input snapshot and delivery identifier while still checking pause and prerequisites.

**Install:** extract `gptworkbot-1.2.0.zip` and use Chrome's Developer mode to load the folder containing `manifest.json`. The extension is not currently listed in the Chrome Web Store.

**Upgrade:** update the same extension directory, reload the extension, save drafts before refreshing ChatGPT, reopen the sidebar and recheck conversations. Existing v2 teams and tasks are retained. Only v1 upgrades require rebinding and reconnecting collaboration.

**Verification:** all 334 tests across 18 files, strict type checking, building and installation-ZIP checks pass. Read-only native-page observations and DOM regression tests are recorded separately. Complete installed-extension workflows remain manual acceptance items; see the [verification record](../verification.md).

Assets: installation ZIP and offline bilingual homepage ZIP. Historical packages and archives are unchanged.
